# AI Prompts & Workflow Log

This document tracks meaningful AI-assisted interactions throughout the development of the Sales CRM application.

## Workflow Structure
Each significant entry records:
- **Date - Prompt Number - Feature / Stage / Phase**
- **Problem / Task**: Objective and context of the interaction.
- **User Intent**: What the user was aiming to achieve.
- **Prompt given to ChatGPT (when relevant)**: Exploratory, architectural, or meta-prompting input provided to ChatGPT.
- **Important ChatGPT recommendation**: Architectural guidance, structured system instructions, or prompts generated by ChatGPT.
- **Brief prompt sent to IDE / Code Assistant**: Crisp, actionable prompt provided to the IDE code agent.
- **What IDE / Code Assistant implemented**: Exact code, configuration, or structural response provided.
- **Human review / testing**: How the implementation was verified.
- **Corrections or rejected suggestions**: Any changes made to AI suggestions, hallucinations, or anti-patterns.
- **Final outcome**: The end state of the task.

  - Adopt **application-level soft delete** for Deals (`deletedAt: DateTime?`, `deletedById: String?`).
  - Never hard-delete deals physically from the database.
  - Preserve `DealHistory` permanently for the lifetime of the record; do NOT use `ON DELETE CASCADE`.
